\section{Executive Summary}

The PathRAG portfolio track has been closed under
\texttt{CLOSED\_AS\_HONEST\_NULL\_RESULT\_FOR\_SEMANTIC\_LAYER\_ABLATION}.

The paper-derived structural comparator was built, tested, and
empirically evaluated at full canonical scale across seven
external datasets and 29{,}718 canonical queries. Its retrieval
metrics are low because it is a structural-only abstraction
without a semantic layer. This is not a bug and not an
implementation failure. It is the expected behavior of a
structural-only retrieval pipeline.

The paper-described PathRAG uses entity and relation extraction
plus embeddings. That layer is absent by design in this
comparator, in accordance with the frozen clean-room contract.
The comparator's low metrics therefore do not indicate that the
native PathRAG architecture is weak.

Two preregistered amendments (v2.0 and v2.1) attempted to
realize the frozen three-edge policy. Both failed for the same
root cause: the canonical structural unit representation is a
whitespace-joined token sequence with no line structure.
Anchor patterns requiring line boundaries cannot match. A third
amendment was not pursued, to avoid post-hoc tuning.

The native PathRAG implementation exists locally but is
\texttt{BLOCKED\_ON\_LICENSE} and not executed. The semantic
extension of the comparator is deferred to a future generation.

\section{What was built}

The paper-derived structural comparator implements:

\begin{itemize}[leftmargin=*]
    \item canonical source mapping with duplicate-content lineage
    \item deterministic structural-unit segmentation (224-token windows, 192 stride, 32 overlap)
    \item structural adjacency graph (one directed edge per adjacent window pair within a document)
    \item query-node selection by deterministic lexical overlap over source mapping text
    \item bounded simple-path enumeration (maximum 3 hops, cycle-free)
    \item resource propagation with decay and threshold pruning
    \item path scoring with frozen coefficients (0.4 / 0.4 / 0.2)
    \item deterministic ranking and document expansion
    \item full pipeline persistence with checksum closure
    \item deterministic storage equivalence across independent processes
\end{itemize}

\section{Root cause}

Two independent causes, neither of which is a bug:

\begin{enumerate}[leftmargin=*]
    \item \textbf{No semantic layer.} No embeddings, no entity extraction, no cross-document semantic edges. The comparator is a structural-only paper-derived abstraction.
    \item \textbf{Topological bound.} With \texttt{maximum\_hops=3} and intra-document linear-chain topology, only query-node pairs within three consecutive structural units of the same document are reachable.
\end{enumerate}

\section{Amendments attempted}

Two preregistered amendments were made to try to realize
the frozen Step 96 three-edge policy (STRUCTURAL, CONTAINMENT,
EXPLICIT\_REFERENCE):

\begin{longtable}{lll}
\toprule
Version & Goal & Outcome \\ \midrule
v2.0 & headings-only target index & nearly zero edges \\
v2.1 & inline declaration anchors & 9 edges in 7000-unit sample \\
\bottomrule
\end{longtable}

Both failed for the same root cause: canonical unit text has
no line structure. Anchor patterns requiring \texttt{\^{}} or
\texttt{\textbackslash n} boundaries cannot match.

A third amendment was not pursued. It would risk post-hoc
tuning and would not change the fundamental structural
limitation. Changing the canonical representation would
invalidate node identity and break comparison to v1.

\section{Fair comparison principle}

The comparator's results must not be presented as evidence
about the native PathRAG architecture. They are evidence about
the structural-only abstraction. Fair comparison requires
equal semantic layers across architectures.

The primary portfolio comparison will therefore be restricted
to architectures with comparable semantic layers: my\_rag,
LongRAG, and semantic baselines such as BM25 and dense
retrievers.

The PathRAG track is closed for the portfolio.

\begin{itemize}[leftmargin=*]
    \item \textbf{LongRAG} full pipeline (L1--L7)

\section{What this track establishes}

\begin{itemize}[leftmargin=*]
    \item PathRAG paper-derived structural comparator executes deterministically end-to-end at full canonical scale.
    \item Pipeline is resumable without corrupting prior artifacts.
    \item Ground-truth evaluation runs in an isolated evaluator process that does not modify retrieval artifacts.
    \item Storage equivalence holds for non-degenerate datasets across independent processes.
    \item No evaluative field value entered any runtime object or committed artifact.
    \item Graph state remained read-only across every execution.
\end{itemize}

\section{What this track does NOT establish}

\begin{itemize}[leftmargin=*]
    \item Native PathRAG performance (license-blocked).
    \item Semantic PathRAG performance (deferred).
    \item Publishable results.
    \item Cross-architecture comparison claims (requires equal semantic layers).
\end{itemize}
