\section{Executive Summary}
% =====================================================================

\section{v1 vs v2 Evaluation Boundary}
% =====================================================================

\begin{warnbox}{Critical note για SAH-RAG numbers}
Τα v1 SAH-RAG νούμερα (macro Recall@10 = 0.4049, +28.79\% vs LongRAG) είναι \textbf{v1 semantics}:
\begin{itemize}[nosep]
  \item CUTOFFS = (1, 5, 10, 20, 50)
  \item No metric\_version field
  \item Artifact type: my\_rag\_m0\_evaluation\_report
\end{itemize}

\textbf{NOT directly comparable} to v2 baselines (CUTOFFS = [1, 5, 10], metric\_version = "v2", hit@k field).

\textbf{Preserved artifacts:} \texttt{outputs/external\_sah\_rag/} (39.4 GB, SHA-256 verified).

\textbf{For v2-compatible numbers:} re-run v1 retrieval results through v2 evaluator. See \texttt{docs/evaluation\_boundary\_v1\_v2.md}.
\end{warnbox}

\section{Fairness Policy (Finalized)}
% =====================================================================

\begin{okbox}{LLM Fairness}
\textbf{Native mode:} κάθε baseline με το δικό του native LLM. Αν χρειάζεται paid API → εξαίρεση (μόνο controlled). \\
\textbf{Controlled mode:} κοινό \texttt{Qwen2.5-14B-Instruct} (indoor) + \texttt{Qwen2.5-32B-Instruct} (generation). \\
\textbf{Fallback:} αν το 32B δεν είναι διαθέσιμο → Qwen 14B για generation (documented). \\
\textbf{Enforcement:} \texttt{QwenLLM.strict\_fairness=True} (mandatory, guards against non-14B substitution). \\
\textbf{Documented:} \texttt{docs/llm\_fairness\_policy.md} + \texttt{baseline\_audit/llm\_fairness\_policy.yaml}.
\end{okbox}
